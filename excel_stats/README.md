# محلل ملفات Excel

مشروع بايثون يقرأ ملف Excel، يمر على جميع أوراقه، يكتشف نوع كل عمود تلقائياً، ثم ينشئ تقريراً إحصائياً ورسومات مناسبة اعتماداً على نوع البيانات واسم العمود.

## المخرجات

| المخرج | الوصف |
|---|---|
| `report.xlsx` | ملخص لكل ورقة، وإحصائيات الأعمدة، ونسب القيم المفقودة |
| `charts/<اسم الورقة>/` | ملفات PNG للرسومات المولدة تلقائياً |

يولد المشروع رسماً للاتجاه الزمني عند وجود عمود تاريخ وعمود رقمي، ورسم أعمدة عند وجود عمود تصنيفي ورقمي، وتوزيعاً لكل عمود رقمي، ومصفوفة ارتباط عند وجود عمودين رقميين أو أكثر، ورسم تكرارات عند غياب الأعمدة الرقمية.

## التثبيت

من مجلد المشروع نفّذ:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r excel_stats/requirements.txt
```

## التشغيل

```bash
python -m excel_stats path/to/data.xlsx --output output
```

مثال:

```bash
python -m excel_stats sales.xlsx --output results
```

بعد التنفيذ ستجد التقرير في `results/report.xlsx` والرسومات داخل `results/charts/`.

## كيف يتم اكتشاف الأعمدة؟

يتم تصنيف الأعمدة إلى رقمي، تاريخ/وقت، تصنيفي، نصي، أو فارغ. ويُستخدم اسم العمود ضمن عنوان الرسم، بينما يعتمد اختيار نوع الرسم على نوع البيانات. لذلك يمكن استخدام أسماء عربية أو إنجليزية مثل `التاريخ`، `date`، `المبيعات`، `sales`، `المدينة`، أو `category` دون إعدادات إضافية.

## استخدام المكتبة داخل كود آخر

```python
from excel_stats import analyze_excel, export_results

results = analyze_excel("sales.xlsx", "output/charts")
report_path = export_results(results, "output")
print(report_path)
```

إذا كانت لديك قاعدة خاصة مثل أن عموداً معيناً يمثل المبيعات أو أن عموداً معيناً يجب أن يكون محوراً زمنياً، يمكن لاحقاً إضافة ملف إعدادات JSON لتحديد ذلك يدوياً.
